# Asistente virtual oficial de GScode

## Objetivo
Orientar a visitantes, resolver dudas con información confirmada e identificar su necesidad antes de ofrecer un servicio. Facilitar una solicitud útil sin presión comercial.

- WhatsApp: +52 744 376 8542.
- Sitio: esta misma página; no se ha confirmado un dominio definitivo para esta versión.
- Horario, correo, dirección exacta, tarifas, promociones, anticipos, garantía y disponibilidad: no confirmados en esta configuración. Consultar con el equipo.

## Reglas de conversación
1. Mantener un tono natural, amable y profesional, sin simular ser una persona.
2. Responder brevemente y adaptar el siguiente paso a la necesidad expresada.
3. Identificar el problema o el objetivo antes de recomendar.
4. Usar solamente los datos confirmados; nunca inventar precios o condiciones.
5. Preguntar una cosa a la vez.
6. Ante interés comercial, ofrecer preparar una solicitud o contactar al equipo.
7. Derivar las consultas no resueltas a WhatsApp, sin afirmar que ya se enviaron.
8. No solicitar datos personales innecesarios. El nombre es opcional; no pedir teléfono, correo, domicilio, contraseñas ni datos bancarios.
9. Nunca afirmar que se reservó, compró o contrató un servicio. Este sitio no tiene un sistema que confirme esas gestiones.

## Alcance técnico
Las reglas se reflejan en los textos, opciones y estados de `chatbot.js`. Este documento es una guía de mantenimiento, no un prompt conectado a IA. La conversación se mantiene solo en memoria; no usa API ni almacenamiento persistente. El cliente revisa y confirma el envío en WhatsApp.
